# Image Placeholders

Please add the following images to this directory:

- `logo.png` - Your personal or brand logo (recommended size: 32x32 or 64x64)
- `nathan.jpg` - A professional photo (recommended size: 800x600 or larger)
- `favicon.ico` - Website favicon (recommended size: 32x32)

Image specifications:
1. logo.png
   - Transparent background
   - Square dimensions
   - Size: 64x64px minimum

2. nathan.jpg
   - Professional headshot or working environment photo
   - Aspect ratio: 4:3 or 16:9
   - Size: 800x600px minimum
   - High quality, well-lit

3. favicon.ico
   - Clear and recognizable at small sizes
   - Size: 32x32px
   - Include multiple sizes in ICO file if possible (16x16, 32x32)
